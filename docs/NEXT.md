# 下一步

## 先验证

- 邀请 5–10 位目标学生完成三次学习：首次学习、次日复现、变式迁移。
- 观察他们是否理解“本地通过”和“官方通过”的区别。
- 记录完成一题所需时间、在哪一步退出、提示使用层级和错误分类是否够用。
- 验证 15 / 25 / 45 分钟队列是否符合真实学习节奏。
- 若需要 24 小时稳定公开访问，迁移到不会随开发工作空间休眠的静态托管服务。

## 再扩内容

- 根据测试反馈修订当前 13 道题的解释与提示。
- 为每个知识模块补齐前置概念卡和更多边界测试。
- 逐批扩充到完整目标题集，每批都运行参考实现回归测试。
- 引入同模式的原创微变式，避免只记住代码文本。

## 暂不进入验证版

- 多语言、云端判题、账号与跨设备同步。
- 付费大模型、聊天式助教、社区、排行榜与连续签到惩罚。
- 抓取 LeetCode 数据、代登录、代提交或读取用户 Cookie。
