# 下一步

## 0.4.0 发布后

- 在 Vercel 生产地址继续抽测新增的树序列化、最短路、最小生成树与位运算题；拓扑排序题和新增题搜索已经通过首轮验收。
- 在线抽测题目来源链接、解法展开中的“题目索引”标签，以及从 Cloud Studio 切换域名后通过备份恢复学习数据的流程。
- 观察 Vercel Hobby 的 Fast Data Transfer 使用量；公开测试规模明显增长或进入商业用途前升级合适方案。
- 准备稳定的自定义域名后绑定 Vercel，并把产品对外链接从平台子域名迁移到自有域名。
- 正式商业化前，由熟悉知识产权与平台条款的律师复核题号／标题／链接的说明性使用及侵权通知流程。

## 发布后验证

- 在实际 Cloud Studio URL 验证首次离线后的提示；CDN Pyodide 和 Service Worker 更新接管已通过线上验收。
- 在 Safari 与真实移动设备上复核编辑器退出手势、底部导航安全区和长题库筛选。
- 继续改善站内 `solve` 适配签名与外部练习签名之间的迁移提示，不复制第三方题面或代码模板。
- 为高风险结构题增加对象身份、原地修改和输入恢复属性测试。

## 更新后验证

- 邀请有编程经验的用户完成首次导入、日常复习和题解对照。
- 记录导入失败原因、回忆耗时、解法展开率和复习评分。
- 验证四阶段简化流程是否比旧版五阶段流程更适合高频复习。
- Vercel 已提供 24 小时稳定公开入口；Cloud Studio 继续只承担开发与应急预览，不再作为正式公开地址。

## 暂不进入验证版

- Python 之外的语言、云端判题、账号与跨设备同步。
- 付费大模型、聊天式助教、社区、排行榜与连续签到惩罚。
- 抓取 LeetCode 数据、代登录、代提交或读取用户 Cookie。
