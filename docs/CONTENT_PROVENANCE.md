# 内容来源与版权边界

## 版本范围

本文件适用于 `0.3.2` 起的回写精选内容；`0.4.0` 扩充为“回写精选 150”。它记录工程层面的内容来源与审查规则，不构成第三方授权声明或法律意见。

## 内容分层

| 内容 | 来源与处理方式 |
| --- | --- |
| 题号、简短标题、外部链接 | 仅作为定位外部练习的索引元数据，不构成题库名称或合作声明 |
| 问题摘要、提示与步骤 | 回写独立概述，不收录完整第三方题面、约束、官方示例或图片 |
| Python 参考实现 | 回写独立编写；只表达通用算法思想，不复制第三方题解的文字、结构性注释或特色命名 |
| 本地测试 | `0.3.2` 重新设计输入并由参考实现计算预期结果，不采用题目来源平台公开示例 |
| 主题和顺序 | 采用回写自有主题顺序，不宣称复刻任何第三方榜单顺序 |

## 数据内的来源字段

`dist/curated-problems.js` 是唯一内置内容入口。`0.4.0` 的新增范围和筛选依据记录在 `docs/SELECTION_150.md`。每道题必须包含：

- `contentOrigin: "huixie-editorial"`；
- 从 1 连续编号的 `curationRank`；
- `referenceUrl`，只用于跳转到外部题目页面；
- 至少两组回写自编本地测试；
- 每份解法的 `source.type: "problem-index"`，明确链接指向题目索引，不把它描述成解法来源。

机器可读清单位于 `docs/content-provenance.json`。摘要、提示、解法和测试的组合哈希用于发现未经记录的内容漂移，不代表第三方授权。

## 自动检查

```bash
node scripts/generate-content-provenance.mjs --check
node scripts/verify-content.mjs
node scripts/verify-content-policy.mjs
```

检查覆盖内容数量、稳定 ID、精选顺序、索引链接、来源标签、解法与测试完整性，以及用户可见区域中的高风险命名。

## 后续内容规则

- 新内容不得从第三方页面自动抓取、批量搬运或镜像。
- 不录入完整题面、约束、官方示例、截图、品牌视觉或付费内容。
- 参考公开资料时，只学习算法思想；最终文字、代码、变量命名和测试独立完成。
- 用户导入的题库必须与内置题库分开标识，并由上传者确认拥有必要权利。
- 收到可核验的侵权通知时，先下架争议内容，再完成来源核查与替换。
