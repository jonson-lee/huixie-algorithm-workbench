# MVP workspace

Scope: a single-route, desktop-first Web learning workspace with Today, Route, Progress, and an immersive problem session. Visitor mode: Operate. The primary user is an algorithm beginner who knows basic Python syntax. The primary task is to complete the next scheduled recall step without deciding what to study.

The experience must demonstrate the answer-first loop with original learning content, graded hints, local learning checks, device-local persistence, and an explainable review schedule. It must not imply official LeetCode affiliation or authoritative judging. Mobile prioritizes review and planning rather than a miniature IDE.

## Direction contract

THESIS: Treat learning as a working circuit: understanding supplies current, retrieval closes the loop, and weak prerequisites visibly interrupt the path. Refuse both the generic analytics-card dashboard and the dark neon coding terminal.

OWN-WORLD: A cool ceramic breadboard surface carries graphite modules, cobalt traces, and one sharp chartreuse current. Thin conductive rules connect square, precisely labeled components; state is expressed by connected, open, or pulsing paths rather than decorative badges.

STORY: The learner sees one recommended circuit for today, starts the next module, studies a worked solution, disconnects the scaffold, reconstructs the plan, writes Python, and reconnects the problem to its next review date.

FIRST VIEWPORT: A compact top rail names 回写 and the three destinations. Below it, a narrow left rail shows today's load and prerequisite voltage; the dominant center is a live horizontal learning circuit with the next problem enlarged as the active module, its five stages visible as connected nodes, and one unmistakable 开始今天的训练 control. A right evidence strip shows stable mastery and the reason this item was selected.

FORM: Electronics breadboard / university training kit, sixth in the grounded direction list; seed key fa4390dc. The signature interaction is 断开支架: the worked-solution module retracts, its trace opens, and the blank editor expands into the freed space. HyperCard contributes visible backtracking through stages; seven-segment instrumentation contributes deliberately designed inactive states; tensegrity contributes one underlying dependency graph for both visuals and scheduling.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
